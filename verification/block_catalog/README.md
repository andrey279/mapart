# Палитра без дублирующих цветов — Java 26.3

В активном каталоге **60 материалов**, по одному на каждый базовый цвет карты Minecraft. Из прежних 685 вариантов удалены **625 дублей**. Сохранились 60 плоских цветов в 2D и все 180 оттенков лестницы 3D, включая их порядок при подборе цвета.

Прежние первые 38 материалов (шерсть, терракота и шесть дополнительных блоков) сохранены. Ещё 22 материала добавляют недостающие цвета. При выборе представителя предпочтение отдано обычным стабильным блокам без обязательных опор. Сохранены, в частности, бледнодубовые доски, еловые доски, багровые и искажённые материалы, горизонтальный блок бамбука, грибная ножка, плита из глубинносланцевого кирпича и блоки металлов.

Бетон и глазурованная терракота повторяют цвета шерсти. Тополевые доски совпадают со светло-серой шерстью, чернит — с чёрной шерстью, красный грибной блок — с красной шерстью, коричневый грибной блок — с землёй. Эти варианты больше не появляются в списках материалов и генераторе QR. Пустые группы и кнопка бетона также удалены.

- [Оставшиеся 60 материалов с проверенными RGB и состояниями](unique_materials.json).
- [Удалённые варианты и их оставшийся эквивалент](removed_aliases.json).
- [Полный отчёт удаления дублей](deduplication.json).

Удалённые имена принимаются только при чтении старых профилей и параметров CLI и преобразуются в оставшийся блок с точно таким же цветом карты. Это не возвращает дубли в активную палитру. Экспорт NBT использует только оставшиеся материалы; при сохранении профиля через GUI имена также становятся каноническими.

## Проверка

Проверены уникальность RGB каждого из 60 материалов и соответствие всех 625 старых имён цветам официального реестра. Список 180 оттенков после удаления дублей совпадает с [сохранённой палитрой до изменения](before_dedup_palette.json), включая порядок. Это сохраняет выбор цвета при равных расстояниях, а не только множество оттенков.

Настоящий исходник заката повторно обработан через CLI с теми же настройками полной палитры. PNG совпал с прежним файлом побайтово; игровая карта совпала попиксельно. NBT и ZIP успешно созданы и содержат только оставшиеся материалы. [Результаты полного цикла](dedup_integration_check.json).

Все 60 материалов экспортированы в отдельные NBT с тремя оттенками. [ValidateBlocks.java](ValidateBlocks.java) прочитал их ванильным `NbtIo`, разрешил ID и свойства через реестр Minecraft и сравнил цвета из `MapColor.calculateARGBColor()` с `_map.png` по фактическим высотам. Все 180 образцов совпали. [Отчёт ванильной проверки](unique_vanilla_check.json).

Использован установленный официальный клиент 26.3. Его SHA-1 совпал с [метаданными Mojang](https://piston-meta.mojang.com/v1/packages/5df1795e16eea19d75b923d66ecca9ce183353c5/26.3.json): `e877b6a07acd633fb3bb475002175cec036e7b87`. `version.json` задаёт DataVersion 5023. [Происхождение данных](provenance.json).

Прошли `go test ./...`, `go test -tags gui ./...`, `go vet ./...` и `go vet -tags gui ./...`. GUI-тесты проверяют выбор, поиск, группы, сохранение скрытых отметок, импорт профилей и повторное использование видимых строк.

## Воспроизведение

```bash
python3 verification/block_catalog/generate.py
gofmt -w block_catalog_generated.go
go test ./...
go test -tags gui ./...
MAPART_CATALOG_FIXTURES=/tmp/mapart-unique-fixtures \
  go test -run '^TestEveryCatalogVariantCanBuild$' -count=1 .
```

`generate.py` использует `unique_materials.json` и `removed_aliases.json`. В Go генерируются только 22 дополнительных активных материала и таблица совместимости старых имён. Старые 38 индексов не меняются.

Для Java-проверки нужны официальный клиент и его библиотеки. Укажите их через `:` в переменной `minecraft_classpath`:

```bash
javac -cp "$minecraft_classpath" -d /tmp/mapart-catalog-validator \
  verification/block_catalog/ValidateBlocks.java
java -cp "/tmp/mapart-catalog-validator:$minecraft_classpath" ValidateBlocks \
  /tmp/mapart-unique-fixtures verification/block_catalog/unique_vanilla_check.json
```

## Архив исходного каталога

[blocks_26_3.json](blocks_26_3.json) и [vanilla_check.json](vanilla_check.json) сохраняют первоначальную проверку 685 вариантов, выполненную до удаления дублей. Она использовала [каталог MapartCraft](https://github.com/rebane2001/mapartcraft/blob/master/src/components/mapart/json/coloursJSON.json) и реестр клиента, выгруженный через [InspectBlocks.java](InspectBlocks.java). Эти архивные варианты не включаются в активный список.

Вода требует расчёта глубины и не входит в палитру твёрдых блоков. Железная решётка в 26.3 имеет `MapColor.NONE` и показывает материал под ней. Проверки используют игровые классы и файлы; строительство в запущенном мире не автоматизировалось.
