# Changelog

## Unreleased

The current source tree provides:

- A CLI for image conversion, folder/URL batch processing, preset comparisons,
  JSON profiles and diagnostic output.
- Native Windows and Fyne desktop interfaces with source editing, block
  selection, map painting, fill, eyedropper, zoom and undo/redo.
- Nine presets, Lab/RGB matching, three dithering modes, tone correction and
  automatic/manual masks.
- A deduplicated catalogue of 60 materials, flat 2D and staircase 3D builds,
  legacy block-name compatibility and material/version validation.
- Local QR generation with styling, optional logo and decode verification.
- PNG previews, vanilla structure NBT, CSV materials, placement JSON and ZIP
  packages containing independent map builds.
- CI, platform packaging, draft GitHub releases, Docker CLI builds and
  third-party dependency/font notices.

Repository preparation updates:

- Replaced outdated CLI/GUI documentation with descriptions checked against
  the current source; added the `andrey279/mapart` repository links.
- Replaced speculative architecture and unverified release-history entries
  with the actual source layout and current capabilities.
- Excluded local artwork, output galleries, old binary hash reports and the
  separate unused OpenCV enhancement helper from the publication copy.

No versioned release history has been established in this local preparation.
